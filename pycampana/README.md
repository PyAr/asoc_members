# Datos

Hacia el final del PyCamp distribuímos una encuesta en Google Forms. En general los tiene @Litox (por ejemplo [acá](https://docs.google.com/forms/d/1DT-f5MkHoK2wtunKkBZ7LvrraxWBfmx4m2F-iVIH5TI/edit)).

La planilla resultante es la que usamos.

En el repo dejamos la última versión disponible, por ejemplo [PyCampAna 2024 (Responses) - Form Responses 1.csv](./PyCampAna%202024%20(Responses)%20-%20Form%20Responses%201.csv)

# General experiments

El lab [general_experiments.ipynb](./general_experiments.ipynb) es para jugar, probar, experimentar. Un rejunte de cualquier cosa. Lo dejamos como inspiración para el que saque los stats en el próximo PyCamp.

# PyCamp Analytics (PyCampAna) Report

Cada año clonamos el _pycampana_report_YYYY.ipynb_ del año anterior (por ejemplo [pycampana_report_2025.ipynb](./pycampana_report_2024.ipynb)), creamos uno para este año y listo.
